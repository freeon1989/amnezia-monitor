# Amnezia Monitor для Android

Телефон показывает статус сервера, задержку, CPU, память, пиры WireGuard/AmneziaWG, скорость RX/TX
и топ доменов DNS, если журнал уже есть. Два источника, их можно совмещать:

* панель Amnezia Monitor на компьютере (JSON, только чтение);
* серверы из самого приложения AmneziaVPN — через файл, который выбираете вы.

Пароли SSH из импорта лежат в `EncryptedSharedPreferences` (ключ в Android Keystore). Ключи VPN
(WireGuard/AmneziaWG) приложение не сохраняет. В репозитории секретов нет.

## Откуда AmneziaVPN берёт список серверов

Приложение AmneziaVPN (`org.amnezia.vpn`, клиент на Qt) хранит настройки через `QSettings`.
Ключ списка — `Servers/serversList` (JSON-массив: `hostName`, `userName`, `password`, `port`,
`description`, контейнеры протоколов). На Android файл настроек лежит в **закрытом каталоге**
приложения, обычно:

`/data/data/org.amnezia.vpn/files/AmneziaVPN/AmneziaVPN.conf`

С версии 2.1 значение `Servers/serversList` ещё и **зашифровано** ключом из Android Keystore.
Отдельного ContentProvider с этим списком нет: чужое приложение, включая Amnezia Monitor,
этот файл прочитать не может.

| Способ | Что доступно |
|---|---|
| Без root | Ничего из чужого каталога. Нужен экспорт, который делает сам пользователь. |
| Выбор файла (SAF) или вставка текста | Резервная копия JSON, ссылка `vpn://`, клиентский `.conf`. Это основной путь. |
| С root | Файл настроек можно открыть, но список серверов в нём зашифрован ключом Keystore, который из другого приложения не достаётся. Root не заменяет резервную копию. |

Как выгрузить данные в AmneziaVPN и передать их сюда:

1. **Резервная копия** (предпочтительно): AmneziaVPN → настройки приложения → резервная копия.
   В JSON пароль SSH уже расшифрован. Файл секретный, никому его не отправляйте.
   В Amnezia Monitor: **Настройки → Импорт из AmneziaVPN → Выбрать файл**.
2. **Ссылка `vpn://` с доступом к серверу** (полная, не «только для подключения»).
   Её можно вставить в то же поле. Внутри — JSON, сжатый как Qt `qCompress` (4 байта длины и zlib)
   и закодированный в base64url.
3. **Клиентский `.conf` или `vpn://` без пароля SSH** добавляет только адрес. Нагрузку и пиры
   по SSH снять нельзя. Если этот же хост уже есть в панели на компьютере, цифры подставятся оттуда.

После импорта телефон сам опрашивает сервер по SSH **только командами чтения** (`/proc`, `docker ps`,
`awg/wg show dump`, журнал DNS если он уже включён). Конфигурацию сервера приложение не меняет.
Если панель на компьютере отвечает и в ней есть тот же адрес, повторный SSH не делается — берётся панель
(там есть история).

## Что включить на компьютере

Панель по умолчанию слушает только `127.0.0.1`. С телефона её не видно, пока не сделано одно из этого:

1. **Amnezia Monitor → Настройки → Телефон** — включить «Разрешить чтение с телефона в локальной сети»,
   сохранить, скопировать адрес (`http://192.168.1.104:8765`) и токен. Программа сама начинает слушать
   сеть. В брандмауэре Windows разрешите её для **частной** сети. Телефон и ПК должны быть в одной
   сети или в одном VPN.
2. Командная панель (токен лучше держать в переменной, а не в командной строке):
   ```bash
   AMNEZIA_API_TOKEN='длинный-случайный-токен' \
     python amnezia_monitor.py -c servers.yaml dashboard --host 0.0.0.0 --with-monitor
   ```
   С другого устройства запросы идут с заголовком `X-Amnezia-Token`.
3. SSH-туннель до уже запущенной локальной панели. Токен тогда не нужен, если туннель заканчивается
   на `127.0.0.1` того устройства, где открыт браузер или приложение.

Канал без TLS. Не пробрасывайте порт `8765` в интернет: токен даёт чтение имён клиентов и доменов.
Страница настроек и пароли SSH с телефона недоступны даже с этим токеном.

Нативному приложению CORS не нужен. Если токен включён, панель всё же отвечает на `OPTIONS`,
чтобы браузер с другого сайта мог прислать заголовок.

## Открыть в Android Studio

Нужны Android Studio (JDK 17) и Android SDK 35.

1. **File → Open** и выберите каталог `android/` (не корень репозитория).
2. Дождитесь синхронизации Gradle. Если спросит SDK — поставьте **Android 35**.
3. Подключите телефон (на Xiaomi / HyperOS: режим разработчика, отладка по USB) или запустите эмулятор.
4. Run ▶ конфигурацию `app`.

В приложении: **Настройки → Добавить панель**, адрес и токен, **Проверить**, **Сохранить**.
Список серверов обновляется потягиванием вниз и сам, пока экран открыт (интервал 15–120 с).
В фоне, когда приложение свёрнуто, опрос останавливается.

## Собрать debug APK из командной строки

```bash
# один раз: Android SDK 35 и build-tools 35
export ANDROID_HOME="$HOME/Android/Sdk"    # или путь к SDK
cd android
./gradlew :app:assembleDebug
```

Готовый файл:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Подпись — автоматический debug-ключ Android SDK (`~/.android/debug.keystore`). Его нет в репозитории,
релизный ключ тоже не нужен для этой сборки.

Установка:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

На Xiaomi 15T Pro / HyperOS, если ставите файл вручную: разрешите установку из этого источника
(файловый менеджер или браузер). Debug-сборку система может пометить как из неизвестного источника — это ожидаемо.

Параметры сборки: Kotlin, Jetpack Compose, Material 3, тёмная тема, `minSdk` 26, `targetSdk` 35.
