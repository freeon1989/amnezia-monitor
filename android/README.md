# Amnezia Monitor для Android

Телефон показывает те же данные, что панель на компьютере: статус сервера, задержка, CPU, память,
пиры WireGuard/AmneziaWG (онлайн/всего), скорость RX/TX и топ доменов DNS, если журнал уже есть.
Приложение **только читает** JSON (`/api/health`, `/api/servers`, `/api/server`). По SSH оно не
подключается и пароли серверов не хранит.

Адрес панели и токен чтения лежат в `EncryptedSharedPreferences` (ключ в Android Keystore).
В репозитории секретов нет: при первом запуске список панелей пуст.

## Что включить на компьютере

Панель по умолчанию слушает только `127.0.0.1`. С телефона её не видно, пока не сделано одно из этого:

1. **Amnezia Monitor → Настройки → Телефон** — включить «Разрешить чтение с телефона в локальной сети»,
   сохранить, скопировать адрес (`http://192.168.1.104:8765`) и токен. Программа сама начинает слушать
   сеть. В брандмауэре Windows разрешите её для **частной** сети. Телефон и ПК должны быть в одной
   сети или в одном VPN.
2. Командная панель (токен лучше держать в переменной, а не в командной строке):
   ```bash
   AMNEZIA_API_TOKEN='длинный-случайный-токен' \
     python amnezia_monitor.py -c servers.yaml dashboard --host 0.0.0.0 --with-monitor
   ```
   С другого устройства запросы идут с заголовком `X-Amnezia-Token`.
3. SSH-туннель до уже запущенной локальной панели. Токен тогда не нужен, если туннель заканчивается
   на `127.0.0.1` того устройства, где открыт браузер или приложение.

Канал без TLS. Не пробрасывайте порт `8765` в интернет: токен даёт чтение имён клиентов и доменов.
Страница настроек и пароли SSH с телефона недоступны даже с этим токеном.

Нативному приложению CORS не нужен. Если токен включён, панель всё же отвечает на `OPTIONS`,
чтобы браузер с другого сайта мог прислать заголовок.

## Открыть в Android Studio

Нужны Android Studio (JDK 17) и Android SDK 35.

1. **File → Open** и выберите каталог `android/` (не корень репозитория).
2. Дождитесь синхронизации Gradle. Если спросит SDK — поставьте **Android 35**.
3. Подключите телефон (на Xiaomi / HyperOS: режим разработчика, отладка по USB) или запустите эмулятор.
4. Run ▶ конфигурацию `app`.

В приложении: **Настройки → Добавить панель**, адрес и токен, **Проверить**, **Сохранить**.
Список серверов обновляется потягиванием вниз и сам, пока экран открыт (интервал 15–120 с).
В фоне, когда приложение свёрнуто, опрос останавливается.

## Собрать debug APK из командной строки

```bash
# один раз: Android SDK 35 и build-tools 35
export ANDROID_HOME="$HOME/Android/Sdk"    # или путь к SDK
cd android
./gradlew :app:assembleDebug
```

Готовый файл:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Подпись — автоматический debug-ключ Android SDK (`~/.android/debug.keystore`). Его нет в репозитории,
релизный ключ тоже не нужен для этой сборки.

Установка:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

На Xiaomi 15T Pro / HyperOS, если ставите файл вручную: разрешите установку из этого источника
(файловый менеджер или браузер). Debug-сборку система может пометить как из неизвестного источника — это ожидаемо.

Параметры сборки: Kotlin, Jetpack Compose, Material 3, тёмная тема, `minSdk` 26, `targetSdk` 35.
