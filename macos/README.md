# Amnezia Monitor для macOS

Значок в строке меню показывает статус серверов AmneziaVPN: задержку, CPU, память, пиры WireGuard/AmneziaWG, скорость и топ доменов DNS, если журнал уже есть. Два источника, их можно совмещать:

* панель Amnezia Monitor на компьютере (те же `GET /api/health`, `/api/servers`, `/api/server`, заголовок `X-Amnezia-Token`);
* серверы из резервной копии AmneziaVPN, ссылки `vpn://` или клиентского `.conf`.

Приложение только читает. Конфигурацию VPN оно не меняет. Ключи WireGuard и AmneziaWG из копии отбрасываются. Токен панели, пароль SSH и SSH-ключ (если в копии вместо пароля лежит ключ OpenSSH) хранятся в Связке ключей этой учётной записи macOS (`org.amnezia.monitor.macos`), а не в UserDefaults. В репозитории секретов нет.

Нужен macOS 13 или новее и Xcode 15 (или новее, со Swift 5). Собрать `.app` на Linux нельзя: здесь нет macOS SDK. Логику разбора JSON, `vpn://` и белого списка команд можно прогнать тестами Swift Package на любой машине со Swift.

## Откуда берётся список серверов

Приложение AmneziaVPN хранит серверы в закрытых настройках (`Servers/serversList`). Чужое приложение этот файл не читает, в том числе с правами администратора: с версии 2.1 список ещё и зашифрован. Нужен экспорт, который делаете вы сами.

| Способ | Что попадает в монитор |
|---|---|
| Резервная копия JSON | Имя, адрес, SSH-порт, пользователь, пароль или SSH-ключ |
| Полная ссылка `vpn://` (не «только для подключения») | То же. Внутри JSON, сжатый как Qt `qCompress` (4 байта длины и zlib) и закодированный в base64url |
| Клиентский `.conf` или `vpn://` без секрета SSH | Только адрес. CPU и пиры по SSH снять нельзя |

В AmneziaVPN: настройки → резервная копия. Файл секретный, никому его не отправляйте. Здесь: **Настройки → Выбрать файл** или вставка текста.

Если панель на компьютере уже знает этот адрес и отвечает, повторный SSH не делается — берётся панель (там есть история). Иначе Mac сам опрашивает сервер через `/usr/bin/ssh` **только командами чтения** (`/proc`, `docker ps`, `awg/wg show dump`, журнал DNS, если он уже включён). Команда вне белого списка на сервер не отправляется. Приватный ключ интерфейса из dump не сохраняется.

Ключ хоста при первом успешном входе запоминается в `~/Library/Application Support/AmneziaMonitor/known_hosts` (OpenSSH `accept-new`). Если ключ сервера сменился, опрос останавливается, пока вы не нажмёте «Забыть ключ хоста».

## Что включить на компьютере с панелью

Панель по умолчанию слушает только `127.0.0.1`. С другого Mac её не видно, пока не сделано одно из этого:

1. **Amnezia Monitor → Настройки → Телефон** — «Разрешить чтение с телефона в локальной сети», сохранить, скопировать адрес (`http://192.168.1.104:8765`) и токен. В брандмауэре разрешите программу для частной сети. Оба компьютера должны быть в одной сети или в одном VPN.
2. Командная панель (токен лучше держать в переменной, а не в командной строке):
   ```bash
   AMNEZIA_API_TOKEN='длинный-случайный-токен' \
     python amnezia_monitor.py -c servers.yaml dashboard --host 0.0.0.0 --with-monitor
   ```
3. Панель на этом же Mac на `127.0.0.1:8765` — токен не нужен.
4. SSH-туннель до уже запущенной локальной панели. Если туннель заканчивается на `127.0.0.1` этого Mac, токен тоже не нужен.

Канал без TLS. Не пробрасывайте порт `8765` в интернет: токен даёт чтение имён клиентов и доменов. Страница настроек и пароли SSH настольного агента этому приложению недоступны даже с токеном.

В приложении: **Настройки → Добавить панель**, адрес и токен, **Проверить**, **Сохранить**. Список обновляется сам, пока приложение запущено (интервал 15–120 с, допустимо 15–300). Значок в строке меню: `в сети / всего`.

## Собрать и запустить в Xcode

1. Установите Xcode 15 или новее и один раз откройте его, чтобы докачался macOS SDK.
2. Откройте `macos/AmneziaMonitor/AmneziaMonitor.xcodeproj` (не корень репозитория).
3. Схема **AmneziaMonitor**, цель **My Mac**.
4. В Signing & Capabilities оставьте **Sign to Run Locally** (в проекте уже стоит ad-hoc подпись `-`). Свой Apple ID нужен только если так просит Xcode. Песочница выключена специально: прямой опрос идёт системным `/usr/bin/ssh`, а не из контейнера.
5. Run ▶. В строке меню появится щит. Окно открывается из меню «Открыть окно» или «Настройки». Отдельной иконки в Dock нет (`LSUIElement`).

Командная сборка:

```bash
cd macos/AmneziaMonitor
xcodebuild \
  -project AmneziaMonitor.xcodeproj \
  -scheme AmneziaMonitor \
  -destination 'platform=macOS' \
  -configuration Debug \
  -derivedDataPath build \
  build
open "build/Build/Products/Debug/AmneziaMonitor.app"
```

Готовый пакет:

```text
macos/AmneziaMonitor/build/Build/Products/Debug/AmneziaMonitor.app
```

Установка: перетащите `AmneziaMonitor.app` в «Программы» или

```bash
cp -R "build/Build/Products/Debug/AmneziaMonitor.app" /Applications/
open /Applications/AmneziaMonitor.app
```

Подпись ad-hoc. Gatekeeper при запуске не из Xcode может сказать, что разработчик не опознан: правый клик по приложению → «Открыть», либо «Системные настройки → Конфиденциальность и безопасность». Это ожидаемо для локальной сборки без Apple Developer ID.

Остановка: меню у щита → «Выйти». Автозапуск: «Пользователи и группы → Объекты входа» и добавьте приложение.

Проверка разбора API и импорта без сборки окна (нужен Swift, на Mac его даёт Xcode):

```bash
cd macos/AmneziaMonitor
swift test
```

`swift test` гоняет ту же логику, что Android-клиент: резервная копия, `vpn://`, `.conf`, белый список команд, JSON панели и то, что в UserDefaults не попадают токен и пароль SSH.
